What syncs, and which way

Matching

Items are paired by SKU. Shopify variants carry a SKU field; Vinted has none, so put the same code in the Vinted listing description as SKU: ABC-123 or [ABC-123]. Listings without a SKU fall back to matching on title + size, which is reported but never written to.
